# Web Clone skill

English translation and portable adaptation of Jane (Xiaoer)’s web-clone skill. Upstream: https://github.com/Jane-xiaoer/claude-skill-web-clone

The methodology and helper scripts are licensed under MIT; see LICENSE. The references preserve upstream attributions for adapted methods. Machine-specific Jane paths were removed. The network capture helper was changed to omit request headers and POST bodies and redact sensitive query values.

The scripts require Node.js and Playwright. Review the script help and inspect captured data before sharing it. The helpers were not executed as part of this import.
